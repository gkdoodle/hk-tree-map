# 🌳 香港樹木地圖 (Hong Kong Tree Map)

這是一個基於瀏覽器的高性能香港城市樹木互動地圖，透過 OpenStreetMap 與開放數據視覺化技術，讓大眾輕鬆探索香港的珍貴古樹、石牆樹及各類城市景觀樹木。

## ✨ 主要功能

- **多維度分類著色**：根據官方數據類型與品種自動上色，清晰識別古樹與普通樹木。
- **雙重篩選系統**：支援按「樹木品種」及「樹木類型（古樹名木、石牆樹等）」進行即時篩選。
- **智慧標籤開關**：當放大至街區級別（Zoom 19+）時自動顯示樹名標籤，並設有右下角開關按鈕隨時切換顯示狀態。
- **豐富的彈窗資訊 (Popup)**：點擊樹木可查看中文名（附帶維基百科直達連結）、學術名稱、科名、品種屬性（本地/外來）、地點及官方樹木編號。
- **高效能點群聚 (Marker Cluster)**：採用 Leaflet MarkerCluster 處理海量數據，確保地圖瀏覽流暢。
- **GPS 定位支援**：一鍵定位並顯示用戶當前位置。

## 🛠️ 技術棧

- **地圖框架**：[Leaflet.js](https://leafletjs.com/)
- **點聚類插件**：Leaflet.markercluster
- **CSV 解析**：PapaParse.js
- **地圖底圖**：OpenStreetMap
